# AI Engineer Journey

A 6-month structured learning and project portfolio to transition from Software Engineer to AI Engineer.

## 🎯 6-Month Goal

By **April 30, 2027**, I aim to become a job-ready **AI Engineer** by building and deploying practical AI applications.

### Target outcomes

- Build a strong foundation in Python, NumPy, pandas, and practical math for AI
- Learn machine-learning fundamentals and model evaluation
- Understand deep learning, Transformers, and LLM fundamentals
- Build production-style LLM applications using RAG, APIs, and agents
- Deploy AI services using FastAPI, Docker, and cloud basics
- Create a public portfolio with at least 3 completed AI projects
- Reposition my resume and prepare for AI Engineer interviews
